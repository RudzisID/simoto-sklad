### 2.2. Колонки канбана (статусы)

| ID | Название | Цвет | Логика |
|----|----------|------|--------|
| `new` | Новые | zinc/gray | customerorder в статусе "Новый", не проверен |
| `checking` | Проверяется | yellow/amber | В процессе проверки (polling/scan) |
| `can_ship` | К отгрузке | sky/blue | Проверен, можно создать demand |
| `shipped` | Отгружено | indigo | Demand создан, статус "На отправке/Отгружен" |
| `can_pay` | К оплате | violet/purple | Отгружен, не оплачен (payedSum < sum) |
| `paid` | Оплачено | emerald/green | Полностью оплачен (payedSum >= sum) |
| `can_return` | К возврату | orange | Есть возврат в WB/Ozon, можно вернуть |
| `returned` | Возвращено | red | SalesReturn создан |
| `cancelled` | Отменён | zinc | Статус CANCELLED |
| `delayed` | Отложено | amber | Ручная отложка (drag в эту колонку) |

### 2.3. Карточка заказа (KanbanCard)

```
┌─────────────────────────────┐
│ WB-47              [⋯]       │  ← shipmentNum + меню
│ ┌───────┐                   │
│ │ IMG   │ 2,400 ₽          │  ← thumbnail + сумма
│ └───────┘ 2 позиции         │  ← количество позиций
│ ● WB · 12.10.26 · 14:30    │  ← площадка + дата
│ ─────────────────────────── │
│ [👁️] [📦] [💰] [↩️]       │  ← action buttons (контекстные)
└─────────────────────────────┘
```

**Цветовые индикаторы площадок:**
- WB: фиолетовый (`bg-violet-500`)
- Ozon: синий (`bg-blue-500`)
- Неизвестно: серый (`bg-zinc-400`)

**Action buttons на карточке** (появляются при hover):
- 👁️ — Просмотр (открыть OrderDetailModal)
- 📦 — Отгрузить (доступно в can_ship)
- 💰 — Оплатить (доступно в can_pay)
- ↩️ — Вернуть (доступно в can_return)

### 3.2. Данные

Источник: `MoySkladApiClient.getStockByStore(storeHref)` или `getStock()`
- Остаток (stock)
- Резерв (reserve)
- В пути (inTransit)
- Цена (salePrice)

### 3.3. Условное оформление (цвета)

| Условие | Цвет |
|---------|------|
| stock = 0 | красный фон |
| stock < 5 | жёлтый фон |
| stock >= 5 | без фона |
| reserve > 0 | иконка резерва |

## 5. Polling вместо SSE

### 5.1. Паттерн

```tsx
// Как в tasks: useKanbanRealtime
const { data, isLoading } = useQuery({
  queryKey: ['supplies-orders', filters],
  queryFn: () => sdk.admin.supplies.list(filters),
  refetchInterval: 2000,  // polling каждые 2 сек
})
```

### 5.2. Прогресс сканирования

```tsx
// Redis: supplies:scan:{tenantId}:progress
// { processed: 45, total: 100, wb: 23, ozon: 22, status: 'running' }

const { data: progress } = useQuery({
  queryKey: ['supplies-scan-progress'],
  queryFn: () => sdk.admin.supplies.scanProgress(),
  refetchInterval: 1000,  // опрос каждую секунду
  enabled: isScanning,
})
```

## 6. Drag and Drop (как в tasks)

### 6.1. Библиотека

Использовать `@dnd-kit/core` + `@dnd-kit/sortable` (как в tasks page, если используется) или HTML5 DnD.

### 6.2. Поведение

- Перетаскивание карточки между колонками → смена статуса
- Перетаскивание внутри колонки → смена порядка (lexorank)
- Ограничения:
  - `paid` → нельзя перетаскивать (финальный статус)
  - `cancelled` → нельзя перетаскивать (финальный статус)
  - `shipped` → можно в `can_return` или `can_pay`
